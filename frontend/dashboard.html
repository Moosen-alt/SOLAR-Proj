Start here — how a project flows click to collapse

Every project moves left-to-right through these 7 steps. Pick a project from the list to see its Next step banner, which tells you exactly which button to click.

  1. 1
    Intake

    Open the Parser, upload the plan set + utility bill, click Parse, then Save to project.

  2. 2
    QC check

    Select the project, click Run QC. Fix anything flagged in QC Results, then re-run.

  3. 3
    Build docs

    Click Build AHJ/NEM Docs to generate the application packet.

  4. 4
    Final review

    Click Reviewer Gate — the last automated check before a human submits.

  5. 5
    Submit

    Click Prepare Submittal. A person does the final submit in the portal — automation never clicks submit, pays fees, or solves MFA/CAPTCHA.

  6. 6
    Track

    Use Permit Checks + NEM Checks to monitor. Paste any correction letter into Corrections for an AI-drafted reply (you review before sending).

  7. 7
    Handoff

    When the permit is issued and NEM approved, copy the Handoff Packet to the installer. Our scope ends here — PTO is the installer's job.
