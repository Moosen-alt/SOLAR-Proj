How it flows Show the 5 stages Hide

A project is born in the Parser — upload the plan set + utility bill, click Parse, then Save to project, and it lands on this board already parsed. From there it moves left to right through these five stages. Pick a project from the list to see its Next step banner, which names the button to click.

  1. 1
    QC check

    Select the project, click Run QC. Fix anything flagged in QC Results, then re-run. Missing files are uploaded here too, under Project Documents.

  2. 2
    Build & validate

    Click Build AHJ/NEM Docs, then open Reviewer Gate on the project to check the packet before submission.

  3. 3
    Submit

    Click Prepare Submittal. A person does the final submit in the portal — automation never clicks submit, pays fees, or solves MFA/CAPTCHA.

  4. 4
    Track

    Use Permit Checks + NEM Checks to monitor. Paste any correction letter into Corrections for an AI-drafted reply (you review before sending).

  5. 5
    Handoff

    When the permit is issued and NEM approved, copy the Handoff Packet to the installer. Our scope ends here — PTO is the installer's job.
