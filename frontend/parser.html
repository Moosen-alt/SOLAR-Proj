03 · Review + submit

Hand it to the workflow.

Saving creates or updates the project, uploads the documents against it, and runs QC — a person always approves the final submit.

Choose the Client / Contractor above before saving a new project — the permit application carries that client’s CCB licence and the portal logs in as them, so a project cannot be created without one.

The parser reads documents and proposes values; it never files anything. Final code interpretation and project approval remain with the applicable authority and the responsible project professionals, and a person always performs the final submit.
