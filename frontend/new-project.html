Enter everything you have in one place. Only the homeowner name and install address are required — the parser and knowledge base fill the rest, and blanks can be completed later. Grouped to match the Oregon BCD solar checklist and the utility (PowerClerk) interconnection application.

Homeowner & property

Who owns the system and where it's installed (permit applicant + site address).

Jurisdiction & utility

The permitting authority (AHJ) and the utility that receives the net-metering / interconnection request.

System size & value

Sizing (kW) drives the interconnection tier; job value drives the permit fee.

Equipment

Make/model as printed on the spec ("cut") sheets — the interconnection application and CEC listing check both key off these.
